# Coin Hop: asset list

Every file used by the game, with its source and licence. Nothing else is loaded.

Source: Kenney "Starter Kit 3D Platformer", https://github.com/KenneyNL/Starter-Kit-3D-Platformer (downloaded from the main branch).

| models/coin.glb | Collectable coin | CC0 |
| models/platform.glb | Small platform | CC0 |
| models/platform-medium.glb | Medium platform | CC0 |
| models/platform-large.glb | Large platform | CC0 |
| models/platform-grass-large-round.glb | Round grass platform (downloaded, not used) | CC0 |
| models/flag.glb | Goal flag | CC0 |
| models/cloud.glb | Background cloud | CC0 |

Code in this folder (game.bundle.js, built from src3d/game.js) is written for Polish Quest and uses three.js (MIT).
