PROMPT 8 of 26 - SMOOTH UI
Game: Tiny Boatball! (Roguelike or dungeon run, LOVE (Lua))
Rules this serves: 3 Smooth UI

GOAL
Every popup, button, counter and screen change uses the SAME timing and the SAME easing. Nothing snaps or pops in. Only move and fade things, so it stays smooth on weak phones.

LOOK AT FIRST (read only, change nothing yet)
- Every UI element that appears, disappears, changes number or moves.
- Any place that jumps instantly, or uses a different speed than its neighbors.
- Any animation that changes size of layout, blur, shadows or filters, which are heavier on weak phones.

BUILD (small steps, in this order)
1. Pick ONE short duration and ONE easing curve and define them in one place as shared settings (for example UI_TIME and UI_EASE). Everything below uses them. Write the chosen values in the memory file.
2. Popups: they fade and move a little into place, and fade out the same way. Nothing appears instantly.
3. Buttons: a quick press response (a small scale or brightness change) using the same timing.
4. Counters: numbers roll to the new value with the same timing instead of jumping. Keep the roll short.
5. Screen changes: fade or slide with the same timing.
6. Use only position, scale and transparency changes. Avoid animating things that force the layout to be recalculated, and avoid heavy filters on weak phones.
7. Add a "reduce motion" switch that turns movement down to short fades. It must be easy to find.
8. [ALREADY IN THE GAME - check it works, do not rebuild] If there is a settings screen, add the reduce-motion switch there. Otherwise keep it small and near pause.

DO NOT TOUCH
- Do not change what the UI does or says.
- Do not make animations long. Slow UI feels worse than snappy UI.
- Do not add new animation styles. Use the shared timing and easing only.
- Anything outside this prompt's goal. If you spot another problem, write it under "Seen but not fixed" in the memory file and leave it.
- These files and folders must never be edited (read them if you must, never write):
    toolkit/lib/
- Do not edit third-party library files.

DONE WHEN
- Every UI element I can find uses the shared timing and easing.
- Nothing pops in or snaps out.
- Reduce-motion works.

QUICK TEST (Run the folder with LOVE (love .).)
1. Open and close every popup quickly three times. It should always feel the same.
2. Watch a counter change. It should roll, not jump.
3. Turn on reduce-motion and check that movement becomes short fades.
