BUILD (small steps, in this order)
1. Write a payoff plan in PROJECT_MEMORY.md as a table with one row per beat (loss, sacrifice, reunion, victory). For each row: does it fit this game (yes or no), what is SET UP before it (at least two earlier moments), where it lands, and which tools pay it off (cinematic, finisher, music shift, quiet moment).

6. A loss must be fair and never feel like a trick. It must not erase the player's saved progress as a punishment.
