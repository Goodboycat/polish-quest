GOAL
Add short story moments to Tiny Boatball! at three places: the start, a few key turning points, and the ending. Build them inside the game from its own art and code. No video files. Characters sound different from each other. One tap skips. The game remembers what the player already saw.

- The art the game already has (characters, backgrounds, portraits). The cinematics may only use what exists, unless I say otherwise.
- Where a roguelike or dungeon run game can safely pause for a few seconds (between rooms, levels, rounds or turns), so a story moment never lands in the middle of a hard moment.

BUILD (small steps, in this order)

3. Build ONE small cinematic runner. A cinematic is a list of beats written as data (who, what they say, what the camera does, how long to wait). The runner plays the beats using the shared UI timing from Prompt 8. Write lines as data so Prompt 20 can reuse them.
4. Add black bars at the top and bottom that slide in and out. Only move and fade, so it stays smooth on the weakest phone.
5. Make every cinematic skippable with ONE tap anywhere. Skipping must leave the game in exactly the same state as watching to the end (same flags, same rewards, same position). Test both.

7. Write exactly three kinds: a START moment (about 15 to 20 seconds at most: who you are, what is wrong, what you want), 2 or 3 TURNING POINT moments (about 10 seconds each, tied to the milestones), and an ENDING (about 30 seconds at most, the real ending from Prompt 5).
8. Play a cinematic only at a safe pause point. Never during danger. Never while another popup is open.
9. If there is an audio manager (Prompt 18), use it for a quiet sound under the story. Do not add new sound files. Tell me where one would help.
