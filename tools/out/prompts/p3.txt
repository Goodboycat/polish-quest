Game: Tiny Boatball! (Roguelike or dungeon run, LOVE (Lua))

GOAL
Create a 60-second check that tells us fast whether the game still works, and a small hidden debug view that shows speed and counts. Every later prompt will use these. This is the step that stops "fix one thing, break three".

LOOK AT FIRST (read only, change nothing yet)

BUILD (small steps, in this order)
1. Write a SMOKE TEST in the memory file: 8 to 12 steps a human can do in about 60 seconds. Each step has an action and the expected result (start game, move, act, take a hit, pause, resume, restart, save, load, go back to title). Put in the steps that matter to this game.

4. Add a "perf marker" line to the memory file: a place where we write numbers measured on the weakest phone (frames per second, worst stall, memory if available).
