PROMPT 9 of 26 - NOTIFICATION LOG
Game: Tiny Boatball! (Roguelike or dungeon run, LOVE (Lua))
Rules this serves: 2 Notifications

GOAL
Nothing blocks the screen. Messages, rewards and warnings go into one small collapsible log in a corner. The center of the screen always stays clear.

LOOK AT FIRST (read only, change nothing yet)
- Every message, popup, banner, reward screen and warning in the game today.
- Which ones cover the middle of the screen or pause the game.
- The existing message system, if any. Reuse it.

BUILD (small steps, in this order)
1. List every message type in the memory file (reward, warning, info, achievement, tip) and which ones currently block the screen.
2. Create ONE small log in a corner: new lines slide in with the shared UI timing, stay a moment, then fade into the log. Keep the log tiny when collapsed.
3. Make it collapsible with one tap: collapsed shows a small badge or the newest line; expanded shows the last few lines. Tapping outside closes it.
4. Use a small icon per type (reward, warning, info) instead of long words. Use the game's art, not emoji.
5. Move every message you found into the log. Messages that truly must stop the game (like game over) are the only exception, and they must still be closable with one tap.
6. Cap how many lines exist and reuse the line objects so the log never grows or allocates every frame.
7. Make sure the log never covers the controls, the player or the main action.

DO NOT TOUCH
- Do not add new kinds of messages.
- Do not make the log loud. No sounds, shaking or flashing for it.
- Do not put the log in the middle or over the controls.
- Anything outside this prompt's goal. If you spot another problem, write it under "Seen but not fixed" in the memory file and leave it.
- These files and folders must never be edited (read them if you must, never write):
    toolkit/lib/
- Do not edit third-party library files.

DONE WHEN
- No message covers the center of the screen during normal play.
- The log opens and closes with one tap and holds the recent messages.
- Old messages are removed, so it never fills up.

QUICK TEST (Run the folder with LOVE (love .).)
1. Trigger a reward, a warning and an info message. All three should appear in the corner log.
2. Spam many messages quickly. The log must stay small and the game must not slow down.
3. Check the middle of the screen during the busiest moment of play. It should be clear.
